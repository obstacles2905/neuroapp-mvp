Задача понятна и чертовски красива с инженерной точки зрения. Нам нужно превратить сухую академическую таблицу акустических признаков eGeMAPS v02 в один живой, понятный пользователю индикатор: Voice Stress Index (VSI) от 0% до 100%.

Как математик ты понимаешь, что если мы просто сложим все показатели в лоб, мы получим «среднюю температуру по больнице», которая будет реагировать на индивидуальные особенности голоса (бас у человека или тенор), а не на стресс. Поэтому нам нужна взвешенная кумулятивная модель, которая нормирует каждый показатель и учитывает его физиологический вклад в картину стресса.

Давай выделим из eGeMAPS топ-5 ключевых метрик, которые напрямую отражают физиологию стресса (сжатие гортани, спазм дыхания, выброс кортизола), и соберем их в единую формулу.

Топ-5 метрик openSMILE для кумулятивного индекса

Физиология стресса неизменна: при активации симпатической нервной системы связки натягиваются (растет высота тона), дыхание становится прерывистым (скачет громкость), а контроль над микроинтонациями теряется (появляется микродрожание - тремор).

Вот наши главные маркеры:

F0semitoneFrom27.5Hz_sma3nz_amean (Средняя высота тона)
Физиология: Стресс $\rightarrow$ зажим гортани $\rightarrow$ связки натягиваются как струны. Голос становится неестественно выше базового уровня («писклявость» или «сдавленность»).
F0semitoneFrom27.5Hz_sma3nz_pctlrange0-2 (Размах интонации)
Физиология: Это основа нашего monotonyIndex. При стрессе и депрессивных состояниях голос уплощается, превращаясь в роботоподобную монотонную речь. Диапазон интонаций резко сужается.
jitterLocal_sma3nz_amean (Микроколебания частоты)
Физиология: Микроскопическая нестабильность частоты. Дает нам tremorIndex. Когда нервная система перегружена, моторный контроль связок падает, голос начинает скрыто «дребезжать» (даже если ухо этого почти не ловит).
shimmerLocaldB_sma3nz_amean (Микроколебания громкости)
Физиология: Нестабильность давления воздуха из легких. Из-за зажима диафрагмы выдох идет неравномерно, громкость микро-волнами «плавает».
loudness_sma3_stddevNorm (Нормированное отклонение громкости)
Физиология: Показывает общую динамику речи. При стрессе человек либо начинает говорить на одном удушливом выдохе (низкое отклонение), либо его речь становится рваной и импульсивной (высокое отклонение).
Математическая модель кумулятивного индекса (VSI)

Чтобы свести это к процентам, нам нужно сделать три шага: Нормировать (привести к шкале 0-1), Взвесить (дать каждому признаку свою значимость) и Синтезировать.

Шаг 1: Нормировка индивидуальных признаков ($S_i$)

Каждая метрика openSMILE должна превратиться в субиндекс от 0 (полный покой) до 1 (максимальный стресс). Для этого мы используем функцию сигмоиды или линейное отображение по критическим порогам (которые мы определим на baseline-замере пользователя):

$$Si = \frac{x - x{min}}{x*{max} - x*{min}}$$

Для монотонности (размаха интонации) инвертируем: чем меньше размах, тем выше стресс.

Шаг 2: Распределение весов ($W_i$)

Не все метрики одинаково полезны. Дрожание и монотонность - самые жесткие и трудноконтролируемые маркеры стресса (человек может контролировать громкость, но не может сознательно убрать микродрожание связок).

Распределим веса так, чтобы в сумме они давали $1.0$:

Шаг 3: Финальная кумулятивная формула

Итоговый индекс стресса голоса рассчитывается как взвешенная сумма всех нормированных субиндексов, умноженная на 100 для получения процентов:

$$VSI = \left( \sum_{i=1}^{5} W_i \cdot S_i \right) \times 100\%$$

Как это реализовать в compute-voice-core-metrics.ts

В коде это будет выглядеть как лаконичная функция, которая принимает ваши уже просчитанные внутренние индексы (tremorIndex, monotonyIndex, pitchScore) и склеивает их.

TypeScript

interface VoiceMetrics {

tremorIndex: number; // 0-100 (на основе jitter)

monotonyIndex: number; // 0-100 (чем выше, тем монотоннее речь)

pitchScore: number; // 0-100 (отклонение от baseline вверх)

shimmerScore: number; // 0-100 (микро-колебания громкости)

}

export function calculateCumulativeStressIndex(metrics: VoiceMetrics): number {

// 1. Определяем веса (сумма = 1.0)

const W = {

tremor: 0.30,

monotony: 0.25,

shimmer: 0.20,

pitch: 0.15,

loudnessField: 0.10 // добавочный эмпирический коэффициент

};

// 2. Приводим все внутренние метрики к диапазону 0-1

const sTremor = metrics.tremorIndex / 100;

const sMonotony = metrics.monotonyIndex / 100; //假設 в вашем коде чем выше монотонность, тем выше индекс

const sShimmer = metrics.shimmerScore / 100;

const sPitch = metrics.pitchScore / 100;

// Эмпирический маркер рваности речи (если шаг громкости высокий, добавляем вес)

const sLoudness = (metrics.tremorIndex + metrics.shimmerScore) / 200;

// 3. Считаем взвешенную сумму

const cumulativeValue =

(sTremor * W.tremor) +

(sMonotony * W.monotony) +

(sShimmer * W.shimmer) +

(sPitch * W.pitch) +

(sLoudness * W.loudnessField);

// 4. Переводим в проценты и округляем

const voiceStressIndex = Math.round(cumulativeValue * 100);

// Ограничиваем рамками 0-100 на случай экстремальных всплесков

return Math.max(0, Math.min(100, voiceStressIndex));

}

Критически важный нюанс: Эффект «Первого замера» (Baseline)

openSMILE выдает абсолютные физические величины. Например, у Джона от природы может быть высокий и слегка вибрирующий голос, и без калибровки система выдаст ему 75% стресса в состоянии полного покоя.

Чтобы кумулятивная метрика не врала, в compute-voice-core-metrics.ts должна быть заложена дельта с бэйзлайном:

При первом запуске (или в идеальном спокойном состоянии) приложение снимает эталонный WAV.
Мы сохраняем его значения (например, средний Jitter = 0.02, средний F0 = 120 Гц).
При повторных замерах (через 3 и 6 месяцев) формула считает отклонение от этого индивидуального эталона Джона. Именно это отклонение и превращается в субиндексы $S_i$.
